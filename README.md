# منصة متابعة متقدمي مشروع الحصر الخرائطي

## الملفات

- `index.html`: الهيكل العام ونقاط تحميل المكتبات.
- `styles.css`: التنسيق الأصلي مع تحسينات الاستجابة للكمبيوتر والهاتف.
- `app.js`: منطق التطبيق، المصادقة، Supabase، البحث، التقارير، Excel والصلاحيات.

## الربط بقاعدة البيانات

تم الحفاظ على نفس `SUPABASE_URL` و`SUPABASE_KEY`، ونفس الجداول والحقول المستخدمة في النسخة الأصلية: `profiles`, `governorates`, `districts`, `applicants`.

## الدور الجديد

أضيف الدور `followup` باسم **مسؤول متابعة**. يمكنه الدخول إلى لوحة التقارير ومشاهدتها، بينما لا تظهر له أزرار تصدير Excel أو تصدير البيانات، ولا يستطيع فتح سجل المتقدمين من واجهة التطبيق.

لإنشاء الحساب: من إدارة المستخدمين اختر `مسؤول متابعة (مشاهدة التقارير فقط)`، ثم أدخل UID الخاص بحساب Supabase Auth والبريد الإلكتروني.

> ملاحظة أمنية: إخفاء الأزرار والمنع داخل JavaScript يحسن تجربة الاستخدام، لكن enforcement الحقيقي يجب أن يكون عبر سياسات RLS في Supabase. يجب إضافة سياسة قراءة للتقارير/الحقول التجميعية للدور `followup`، ومنع أي صلاحيات كتابة أو تصدير خام حسب تصميمكم الأمني، مع عدم تغيير أسماء الجداول والحقول.

## التحسينات المنفذة

تم فصل المشروع إلى ملفات مستقلة، وإضافة تخطيط متجاوب للهاتف، وتحسين الأزرار والنماذج والجداول، وإضافة فرز بالاسم والحالة والقسم وآخر تحديث، مع الإبقاء على البحث والفلاتر الحالية. كما تم الحفاظ على استيراد Excel مع معاينة الفروقات والتحديث الانتقائي وإضافة المتقدمين الجدد، وعلى تقارير المحافظات والأقسام والمؤهلات والعمل خارج المحافظة.
